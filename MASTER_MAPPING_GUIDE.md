| :--- | :--- | :--- |

| **SpectralRange** | `Waveband` | Mapped to SMU categories (VIS, NIR, SWIR, etc.). |

| **SpatialResAcross_m** | `Resolution` | Parsed for meter values (handles modes and ranges). |

| **Taskable** | `Mission Status` | 'Y' if "operational", else 'N'. |

## 3. The "Best-of-Both" Merge Logic
**Script:** `ultimate_smu_merge.py`

When a satellite and instrument match is found between CEOS and OSCAR (using fuzzy matching > 80%), the following "Best-of-Both" rules are applied to the final row:

| Feature | Conflict Resolution Rule | Reason |
| :--- | :--- | :--- |
| **Altitude** | **Prefer OSCAR** | OSCAR is the verified authority for orbital parameters. |
| **Bands** | **Pick MAXIMUM** | If sources differ, we assume the more detailed one is correct. |
| **Resolution** | **Pick MINIMUM** | We keep the "best" (smallest number) resolution available. |
| **Provider** | **Prefer OSCAR** | OSCAR uses cleaner, standardized agency acronyms. |
| **New Records** | **Add All Unique** | Any OSCAR missions not in CEOS are added as new rows. |
